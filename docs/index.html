The question

Should an agent save the memories it rewrites?

When an agent recalls a memory, it rewrites it to fit the conversation. If it stores that rewrite, the memory can drift from what the user actually said. A real case from our development data:

Stored memory · Jun 2
"The user spent $5.29 on coffee."
User, later that day
"…I just spent $6.96 on a coffee, so I'm trying to be more mindful of my expenses."
↓ the agent rewrites the recalled memory ↓
Old rewrite prompt (v4)
"The user spent $6.96 on a coffee and is trying to be more mindful of their expenses."

✗ drift  a different purchase replaced the remembered one

Frozen prompt (v5b)
"The user spent $5.29 on coffee in an earlier conversation on 2025-06-02."

✓ kept  original detail kept, date added

The system

Only the write policy changes

On every user turn the agent retrieves, selects and rewrites memories. The write policy decides what happens to the rewrite. Everything else is identical across conditions.

Rewrite from:

Probe = the detail the user stated (here $5.29). We grade each condition by whether its probes are still in a live memory.
